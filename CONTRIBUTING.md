# Contributing

This Project welcomes contributions, suggestions, and feedback. All contributions, suggestions, and feedback you submitted are accepted under the [Project's license](./LICENSE). You represent that if you do not own copyright in the code that you have the authority to submit it under the [Project's license](./LICENSE). All feedback, suggestions, or contributions are not confidential.

## Label Disputes

If you believe a finding in the golden set is mislabeled (wrong TP/FP decision, severity, or category), open an issue with:

- The finding identifier and PR key.
- Which axis you disagree with (TP/FP, severity, category, scope).
- What you believe the correct label is.
- A short rationale citing the PR context.

Disputes are reviewed by maintainers. Outcomes (upheld, partially upheld, or declined with rationale) are published in the issue thread and fed back into classifier calibration per the methodology.

## Proposing PRs for the Corpus

Currently we are not accepting new additions to the benchmark corpus. We will open this soon and will share instructions accordingly.

## Becoming a Maintainer

Maintainer status is granted by existing maintainers to contributors who have demonstrated sustained, high-quality participation. This typically means:

- Multiple accepted contributions (label disputes upheld, corpus PRs added, or code contributions merged).
- Familiarity with the methodology and its trade-offs.
- A track record of constructive engagement in discussions.

There is no fixed threshold. Existing maintainers will invite contributors when the time is right.
